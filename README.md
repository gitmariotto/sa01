# SA01

Atividade desenvolvida durante o curso técnico de **Desenvolvimento de Sistemas no SENAI**.

## 📚 Sobre

Projeto desenvolvido como parte das atividades práticas da formação técnica, com o objetivo de aplicar os conhecimentos trabalhados em aula e desenvolver a prática de programação.

## 🛠️ Tecnologias

* HTML
* CSS
* JavaScript

## 🎯 Objetivo

Praticar os conceitos apresentados durante a formação e desenvolver uma aplicação utilizando os conhecimentos adquiridos em aula.
